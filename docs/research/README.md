# Research notes

Raw notes measured while building the mod, kept for provenance rather than as
documentation. They record what was tested and what turned out to be false, so a
later change does not re-derive it or repeat a mistake.

- `fribidi-findings.md` — measured fribidi CLI behaviour. The most reusable of
  the four: it is why the mod wraps in logical order and always passes `--nobreak`.
- `tooling-corrections.md` — `claude plugin` subcommands that do exist, with transcripts.
- `validator-report.md` — review findings applied during the build.
- `brief-facts.md` — the starting brief.

They are written as working notes and address the build as it was in progress.
